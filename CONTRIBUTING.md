# Contributing

Thank you for wanting to help. **Bug reports, ideas, questions and missed or wrongly flagged files are welcome as
GitHub issues.** Do not attach live malware to an issue; give its SHA-256 fingerprint instead.

## Code contributions are not accepted for now

Pull requests will be closed without being merged. The project has one owner so that its licence stays simple and so
that it can be licensed commercially later without asking anyone else. If you have a fix, describe it in an issue (in
words, or a short explanation of what to change) and the owner will write it.

If this changes, this file will say so first, together with the terms any contribution would be given under.

## If you change your own copy

You are free to change your own copy under the licence (PolyForm Noncommercial 1.0.0). Please keep these true in
anything you share:

- never upload a user's file; send only fingerprints, and list every outgoing request on the privacy page;
- never change a setting without the user's approval, and keep every change undoable;
- never ship an API key or signing key inside a build you give away;
- no third-party rules, lists, fonts or code unless their licence allows it, credited as in THIRD-PARTY-NOTICES.md.

Tests: see "Tests" in README.md.
